### About

This repository is a collection of various projects in C++, notes (made by ai), tutorial code snippets. 


### Goal 

The goal of this repository is to simply curate free content, which can be used to advance in C++ programming principles by anyone. 


### Structure

Currently the following structure is employed : 

- `week{number}\` : code snippets for concepts of week {number} 
- `Project{number}\` : project made using concepts taught in the corresponding week
- `capstone-project\` : the final project which utilizes all the learnings at the end of the curriculum. 


** All the notes and pdfs are AI Generated.
