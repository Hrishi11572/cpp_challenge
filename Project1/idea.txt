# The Problem statement

The objective is to build a command-line application that reads text files, analyzes their contents, searches for text, and writes statistical reports. You will use this project to practice C++ fundamentals and learn how real programs are organized across multiple source files.

For the initial version, define a word as a sequence of non-whitespace characters. Treat the search as case-sensitive unless you decide to add a case-insensitive option later. 


Project Structure: 

textutil/
├── main.cpp
├── include/
│   └── textutil/
│       ├── stats.hpp
│       ├── file_io.hpp
│       └── search.hpp
├── src/
│   ├── stats.cpp
│   ├── file_io.cpp
│   └── search.cpp
└── README.md


Working commands: 

1. Command 1 / Calculate Statistics
        ./textutil stats input.txt

2. Command 2 / Search Text 
        ./textutil search input.txt "memory"

3. Command 3 / Generate a Report 
        ./textutil report input.txt report.txt


Your project is complete when:
- All three commands work as specified.
- Missing files and invalid arguments produce useful error messages.
- Statistics are correct for empty files, multiline files, and files with repeated whitespace.
- The source code is split across headers and implementation files.
- You can compile and link the program from the terminal.
- You can explain what each module does and why its interface is designed that way.
